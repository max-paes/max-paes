# Max Pães · Vendedor

App dos vendedores Max Pães: pedidos, trocas, contagem de gôndola, checklist de visita e agenda de rota.
Quem tem conta de supervisor abre o painel com as visitas e pedidos de todos os vendedores em tempo real.

- `index.html` — o app (funciona no celular e no computador; pode ser instalado pelo Chrome)
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — instalação e funcionamento sem internet
- `firestore.rules` — regras de segurança do Firebase (vendedor vê só o seu; supervisor vê todos)
